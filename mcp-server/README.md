# type95-mcp-server

MCP server exposing Type95 component docs to AI coding agents (Claude Code,
Cursor, Windsurf, etc.) so they can look up components without you pasting
docs into the prompt.

**Early scaffold**: Type95 has one component today, so this ships 3 tools
instead of a larger surface. `data/mcp-data.json` is generated by
`npm run generate:llms` at the repo root (see `scripts/generate-llms.mjs`)
and grows automatically as components are added — nothing in this package
needs to change.

## Tools

- `list_components` — name + one-line description per component
- `get_component_doc` — full doc (description, polymorphism, import path, Storybook link) for one named component
- `search_docs` — keyword search across component docs and the full `llms-full.txt` reference (tokens, skins, provider usage, component authoring pattern)

## Development

```bash
npm run dev -w mcp-server        # run directly with tsx
npm run build -w mcp-server      # tsup -> dist/index.js
npm run test -w mcp-server       # vitest on the pure data/search functions
```

## Using it from an AI tool

Point your tool's MCP client at the built server:

```json
{
  "mcpServers": {
    "type95": {
      "command": "node",
      "args": ["/absolute/path/to/type95/mcp-server/dist/index.js"]
    }
  }
}
```

Not published to npm yet — this repo isn't published either. Once
`type95` publishes, this can move to `npx type95-mcp-server` the same way
`@mantine/mcp-server` works.
